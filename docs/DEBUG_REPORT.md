# Debug复查报告

2026-10-12，用户授权“debug一遍，然后推送远程账户”。目标仓库为AustinYI111/agent_quant_2，目标分支为 `feature/ashare-multifactor-mvp`。

## 修复

1. 历史截止日运行此前先计算未来标签再清空评价结果。现改为在因子、标签与训练前截断行情和财报，使运行路径及输入哈希均只涉及截止日前数据；新增测试直接检查标签生成器的输入边界。
2. 持有期净收益此前使用总往返费用的线性近似。现改为买入预算除以 `1 + 买入费率`，退出乘以 `1 - 卖出费率`；新增现金流等式测试。
3. 全损后连续零净值会产生除零和NaN。现保留-100%收益与回撤，无法定义的Sharpe输出null；新增严格JSON序列化测试。
4. 已成熟选股组合可能没有完整股票池基准，其均值为NaN会导致JSON写出失败。现将缺失或非有限均值输出null，不伪造超额收益。
5. 拒绝NaN/无限/过大费率、非整数参数、空行情、带时区或空白证券日期/标识；无效截止日不会提前创建输出目录。
6. 清除现金减法的浮点负残差，保留实质负现金错误检查；按交易日分组回测避免逐日全表扫描。
